أرشيف الكويكبات — Asteroid Archive v0.7
Final Audited Edition — النسخة النهائية المدققة
============================================================

منصة عربية–إنجليزية لمراقبة الأجرام القريبة من الأرض، وتضم:
- سجل الاقترابات القريبة من الأرض.
- الكرات النارية والانفجارات الجوية.
- مراقبة CNEOS Sentry الاحتمالية.
- سجل النيازك والبنى الاصطدامية.
- قاعدة SQLite محلية ومحرك تحديث NASA/JPL.
- محاكاة مدارية من JPL Horizons.
- مختبر مقارنة علمية حتى أربعة أجرام.
- تقارير HTML وCSV وحفظ الخرائط بصيغة PNG.

تشغيل البرنامج على Windows
--------------------------
1) فك ضغط الحزمة كاملة في مجلد مستقل.
2) شغّل أحد الملفين:

   تشغيل_أرشيف_الكويكبات.bat

   أو:

   تشغيل_أرشيف_الكويكبات_PowerShell.ps1

3) اترك نافذة PowerShell مفتوحة أثناء استعمال البرنامج.
4) يفتح البرنامج تلقائيًا على عنوان محلي يبدأ عادة من:

   http://127.0.0.1:8872/

خُصص المنفذ 8872 لهذا البرنامج لتجنب تداخل تطبيقات localhost الأخرى. إذا كان مستخدمًا، يختار البرنامج تلقائيًا منفذًا متاحًا بعده ويعرض العنوان الصحيح.

التشغيل اليدوي من PowerShell
-----------------------------
افتح PowerShell داخل مجلد البرنامج ونفّذ:

   py -3 .\server.py --port 8872

أو:

   python .\server.py --port 8872

لا تفتح index.html وحده عند استعمال SQLite أو محرك NASA أو Horizons.
فتح HTML مباشرة مخصص للعرض المحلي الاحتياطي فقط.

فحص النسخة
----------
شغّل:

   فحص_البرنامج.bat

يقوم الفحص بما يأتي:
- تدقيق ملفات Python.
- تدقيق JavaScript عند توفر Node.js.
- اختبار محلل متجهات Horizons.
- اختبار تعيين اسم/رقم الكويكب.
- اختبار محاذاة نقاط الأرض والكويكب بالزمن اليولياني.
- اختبار حساب المسافة وحفظ المسار محليًا.
- اختبار النسخ الاحتياطي واسترجاع قاعدة SQLite.
- تدقيق إصدارات واجهات NASA/JPL المتوقعة.

محرك NASA/JPL
-------------
افتح «محرك NASA» واضغط أولًا «اختبار الاتصال».
تظهر بطاقات مستقلة للخدمات:
- CAD.
- Fireball.
- SBDB.
- Sentry.
- Horizons Lookup.
- Horizons Vectors.

اختبار Horizons لا يكتفي بالاتصال بالخادم؛ بل يطلب جدول متجهات صغيرًا حقيقيًا
ويتحقق من إمكانية قراءته. تنفذ الطلبات بالتتابع، لا بالتوازي، التزامًا بسياسة
الاستخدام العادل لخدمات JPL.

بعد نجاح الاختبار، اختر نافذة الاقترابات وحد السجلات ثم اضغط:

   بدء تحديث NASA/JPL

يمكن إدخال أي عدد صحيح موجب في حقول السجلات، مثل 20 أو 100 أو 2000.
عند فشل الاتصال أو إلغاء العملية، يسترجع البرنامج نسخة SQLite السابقة بدل ترك
قاعدة جزئية. كما تُكتب نسخة البيانات الاحتياطية بطريقة ذرية.

تحميل المسار من JPL Horizons
-----------------------------
1) افتح «المحاكاة المدارية».
2) اكتب اسم الكويكب أو رقمه، مثل:

   99942
   Apophis
   2004 MN4
   433
   Eros

3) حدّد تاريخ البداية والمدة والفاصل الزمني.
4) اضغط «تحميل المسار من Horizons».

مسار العمل المدقق:
- يبحث Horizons Lookup عن الهوية الرسمية والاسم والتعيين وSPK-ID والمرادفات.
- يرفض البرنامج الاسم الملتبس بدل اختيار جسم عشوائي.
- يطلب متجهات مركزها الشمس في مستوى الكسوف J2000 وبوحدة AU وAU/day.
- يطلب متجهات الأرض للفترات الزمنية نفسها.
- يطابق نقاط الجسم والأرض بواسطة الزمن اليولياني TDB.
- يحسب المسافة الأرضية لكل نقطة زمنية.
- يحفظ المسار الناجح مدة سبعة أيام للعمل السريع، ويمكن استعماله دون اتصال لاحقًا.

تنبيه علمي:
«الأقرب ضمن الفترة» هو أقل مسافة بين النقاط الزمنية المحمّلة فقط. لا يمثل لحظة
الاقتراب الدقيقة ما لم يكن الفاصل الزمني صغيرًا بما يكفي. استخدم فاصل يوم واحد
أو أقل في الدراسات القريبة، واستعمل سجل CAD للقيمة الرسمية لأقرب اقتراب.

عند تعذر الإنترنت ولم يوجد مسار محفوظ، يبقى مسار أبوفيس المرجعي المحلي متاحًا،
وهو تقريب كبلري معلّم بوضوح وليس بديلًا عن متجهات Horizons الحية.

مختبر المقارنة
--------------
يمكن إضافة حتى أربعة أجرام من جدول الاقترابات أو بالاسم/الرقم مباشرة.
يعرض المختبر عند توفر البيانات:
- الهوية والتعيين والفئة المدارية.
- حالة NEO وPHA.
- بيانات الاقتراب والمسافة والسرعة.
- القطر والبياض والدوران والنوع الطيفي.
- العناصر المدارية وMOID ورمز جودة المدار.
- الكتلة والطاقة التقديريتين وفق سيناريو كثافة معلّم.

القيم المنشورة تحمل وسم «منشور»، والقيم المحسوبة تحمل وسم «تقديري»، والقيم
غير المتاحة تبقى «غير متاحة» ولا تُستبدل بأرقام مختلقة.

التخزين المحلي
---------------
- data/asteroid_archive.db     قاعدة SQLite.
- data/live-cache.js           نسخة احتياطية من السجلات المحملة.
- data/horizons_cache/         مسارات Horizons الناجحة.
- data/bootstrap.json          بيانات مرجعية للاختبار.
- data/earth_history.json      سجل تاريخ الأرض المرجعي.

المتطلبات
---------
- Windows 10 أو Windows 11.
- Python 3.10 أو أحدث.
- لا يحتاج البرنامج إلى مكتبات Python خارجية.
- الإنترنت مطلوب للتحديث الحي ولتحميل مسارات جديدة من Horizons.
- البيانات المحلية والمسارات المخزنة تبقى متاحة عند انقطاع الإنترنت.
