OVERALL RESULT
--------------
PASS — the packaged local application, database, deterministic Horizons
pipeline, interface references and local HTTP bridge passed the audits listed
below.

1. JPL HORIZONS PATH AUDIT
--------------------------
PASS
- Official Horizons Lookup is used before a vector request.
- Accepts number, name, primary designation, SPK-ID and aliases.
- Ambiguous/no-match results are rejected explicitly.
- Target command is built from the resolved primary designation.
- Vector requests use a Sun-centred frame, ecliptic reference plane,
  ICRF/J2000 orientation, AU-D units and TDB time.
- CSV vector tables are parsed using csv.reader, with a defensive labelled
  parser as fallback.
- Textual Horizons errors inside an HTTP 200 response are detected.
- Asteroid and Earth rows are aligned by Julian date; arrays are not merely
  truncated to the same length.
- Earth distance is calculated at every aligned sampled epoch.
- The interface labels the nearest value as the minimum among sampled epochs,
  not as an exact close-approach instant.
- Successful paths are cached atomically for seven days.
- Offline cache lookup supports the requested label, official name, bare name,
  IAU number, primary designation, SPK-ID and aliases.
- A force-refresh checkbox can bypass a valid cached path.
