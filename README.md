# أرشيف الكويكبات | ALBAZ Asteroid Archive

## الرابط الرسمي للبرنامج | Official Web Application

**https://mralehsas.github.io/ALBAZ-ASTEROID-ARCHIVE/**

**أرشيف الكويكبات** منصة فلكية علمية عربية لعرض وبحث وتحليل بيانات الكويكبات والأجرام القريبة من الأرض، مع أرشفة محلية للبيانات وتتبع مداري وتقارير وأدوات تعليمية وبحثية.

**ALBAZ Asteroid Archive** is a bilingual astronomy web application for exploring, archiving and analyzing asteroids and near-Earth-object data, with orbital tracking, scientific profiles, comparisons and reports.

## المصادر العلمية | Scientific data services

يعتمد البرنامج على الخدمات والبيانات الرسمية المتاحة من **NASA/JPL**، بما في ذلك:

- JPL Close Approach Data (CAD)
- JPL Small-Body Database (SBDB)
- JPL Sentry
- NASA/JPL Fireball Data
- JPL Horizons

كما يتضمن أرشيفًا أرضيًا مرجعيًا لعدد من النيازك والبنى الاصطدامية لأغراض التعليم والسياق العلمي.

## الوظائف الرئيسية | Main capabilities

- متابعة الاقترابات القريبة من الأرض وحفظها في الأرشيف.
- البحث عن الكويكبات وفتح ملفات SBDB العلمية.
- عرض الخصائص الفيزيائية والعناصر المدارية المتاحة.
- تتبع المدار باستخدام JPL Horizons.
- مراجعة بيانات Sentry الرسمية للمخاطر.
- استعراض الكرات النارية والنيازك والبنى الاصطدامية.
- المقارنة والتحليل والخرائط والتقارير والتصدير.
- واجهة عربية/إنجليزية مناسبة للتعليم والمحاضرات والاستخدام البحثي.

## ملاحظة علمية

البرنامج أداة للبحث والعرض والتحليل ولا يستبدل الإعلانات أو التقييمات الرسمية الصادرة عن NASA/JPL أو الجهات العلمية المختصة. تظل القيم والنتائج مرتبطة بالبيانات الرسمية المتاحة وقت الاستعلام أو آخر تحديث محفوظ.
